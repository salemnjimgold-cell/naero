# Recommended Naero Direction

## Decision

Recommend **Direction A — Contextual Compass**.

It best represents Naero because it defines companionship as a product behavior rather than a mascot, chatbot, or warm palette. It answers an unfamiliar-place need with the smallest trustworthy next action, supports both urgency and exploration, and remains useful after initial settlement.

## Design identity resolution

The answer is **C: create a new hybrid**, but the hybrid is semantic rather than a color compromise.

- Preserve from Deep Sea: calm navy depth, strong contrast, technical confidence, restrained borders, existing token/component investment, and global neutrality.
- Preserve from Guided Compass: professional warmth, cream-biased reading surfaces, emerald reserved for guidance, amber for user investment, purposeful motion, and “user is the hero.”
- Discard from Deep Sea: generic blue-tech sameness, decorative ambient loops, and coolness without emotional meaning.
- Discard from Guided Compass: absolute rejection of blue, dark-only assumptions, overly rigid visual prohibitions, and any next-step/progress content unsupported by real data.
- Invent: a source-authority language, an honest sparse-data Home, a durable intent/plan model, a light-mode peer, bidirectional components, and the repeatable **Orient → Explain → Act → Remember** interaction signature.

## Home hierarchy

1. **Context bar:** selected city/location mode, language, and privacy legibility.
2. **Urgent route:** discreet but unmistakable Help now/Safety access.
3. **Next useful step:** one real, source-backed action—or an honest “choose what matters” setup state.
4. **Ask Naero:** context-aware invitation with suggested intents, not a generic empty prompt.
5. **Useful now:** at most one compact module chosen from nearby, saved, recent or source updates.
6. **Resume:** last unfinished user-started action.

No “people like you,” week number, journey count, deadline, or personalized recommendation appears unless it is real, consented and explainable.

## Biggest risk and mitigation

The biggest risk is promising intelligence before Naero has governed data and a durable task model. Mitigate through capability gates: Home renders only evidence-bearing modules; each recommendation carries a reason/source; unsupported states use explicit intent selection; Plan launches only after its content ownership, persistence and freshness contracts pass acceptance tests.

## Implementation stance

Do not implement yet. Owner decisions, content authority model, Home data contract and a staged implementation brief must be approved first.
