# 3C Onboarding Flow

With `newOnboarding=true`, a genuinely new installation follows Welcome → Language → Guest/Auth → Location choice → Context confirmation → Intent → Main. GPS is optional and manual city is presented beside it. Auth success returns to the location step. Intent accepts up to four choices or an explicit “decide later”.

The flow makes no claims about deadlines, arrival dates, progress, nearby people, legal duties, or recommendations.
