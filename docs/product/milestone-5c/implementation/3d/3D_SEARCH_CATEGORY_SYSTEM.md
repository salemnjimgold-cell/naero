# 3D Search and Category System

The restrained hierarchy exposes only gateway-backed categories:

- Essential: Pharmacy, Healthcare, Groceries, Transport.
- Public and everyday services: Public services, Police and safety, Banks/ATMs, Post office.
- Support: Language support, Community resources, Work support.

Practical multilingual terms select the relevant provider category. Specific names filter returned real records; unmatched names produce an empty state rather than unrelated results. No autocomplete, open-now filter, popularity, or recommendation claim is fabricated.
