# 3D Accessibility and RTL

The list is the primary accessible result interface. Search has a label and search action; categories expose selected state; controls meet the 44×44 token minimum; cards have combined name/address semantics; actions have explicit labels; SourceSheet is modal and screen-reader structured.

Arabic uses logical row order, right alignment, mirrored direction icons, wrapping category groups, and Arabic production copy. Device QA covered the landing surface, search, categories, manual context, empty/error state, tabs, and both themes. Real result cards and detail could not be rendered because providers returned no response during the acceptance window.
