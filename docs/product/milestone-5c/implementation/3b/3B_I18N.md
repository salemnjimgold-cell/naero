# 3B Internationalization

All 3B production-visible strings are registered under the `contextual` namespace and merged into the existing English, Arabic, French and Hungarian resources. Automated tests require identical recursive key sets and confirm Arabic native-script content. Existing English fallback remains enabled for runtime resilience.

Localized groups cover trust, freshness, jurisdiction levels, accessibility labels, source fields/actions, empty/error/offline/permission/location/stale/unsupported states.

German is not a current interface locale, but provenance dates accept `de-AT`; components wrap long authority and municipality names, preserve source-language fields and do not assume English-length strings. A native-language content review remains required before release, particularly for legal/administrative nuance.
