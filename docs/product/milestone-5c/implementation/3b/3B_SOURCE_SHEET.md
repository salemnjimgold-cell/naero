# 3B Source Summary and Source Sheet

`SourceSummary` is a compact provenance row for cards, AI answers and Plan items. It shows class, publisher/authority when available and freshness with the most relevant available date. Full mode adds jurisdiction. It never attempts to display every provenance field.

`SourceSheet` is a bottom modal with logical focus/content order:

1. Title and close action
2. Trust class and freshness
3. Publisher/authority and jurisdiction
4. Available date fields with their real meaning
5. Source language and verification metadata
6. AI involvement, assumptions and uncertainty
7. Supporting sources
8. Safe external-source action
9. Optional report-information action

Absent fields are omitted. A missing/unsafe link displays a localized unavailable statement. External opening revalidates the scheme and checks platform capability before leaving Naero. No in-app browser architecture was introduced.
